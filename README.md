# SlimeSound

Готовое Windows-приложение для озвучивания Twitch-чата и передачи активности речи в VTube Studio.

## Скачать

Скачайте `SlimeSound-Windows-x64.zip` на странице [последнего релиза](https://github.com/NTGaMeS12345/SlimeSound/releases/latest), распакуйте архив и запустите `SlimeSound.exe`.

Исходный Unity-проект в этом репозитории не публикуется.
